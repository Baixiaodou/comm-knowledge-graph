## 一句话本质

信号检测 = 判断信号"有没有"（H0/H1 二元假设），核心是匹配滤波器 + 似然比检测。

## 匹配滤波器（输出 SNR 最大）

- 白噪声背景：传输函数 = 输入信号频谱的复共轭（幅频正比、相频互补，T 时刻同相叠加成峰值）
- 色噪声背景：白化滤波（把色噪声变白）+ 白噪声匹配滤波（级联，广义匹配滤波）
- 匹配滤波器与相关器等价（白噪声下输入结束时刻输出相等）
- 观测时刻选信号末尾：t0=T 时 SNR 最大

## 似然比检测（统一框架）

所有检测准则都是似然比检测，只是门限 η 不同。似然比 Λ(x) = p(x|H1)/p(x|H0)，与门限 η 比较。

| 准则 | 使用条件 |
|------|---------|
| 贝叶斯准则 | 似然/先验/代价均已知 |
| 最小平均错误概率 | 先验已知，代价相同 |
| 最大后验概率 | 先验已知 |
| 极大极小化 | 先验未知 |
| 奈曼-皮尔逊 | 给定虚警概率求最大检测概率 |
| 最大似然 | 先验和代价均未知 |

## 4 类判决概率

- 虚警概率 PF（H0 为真判 H1）+ 正确拒绝 = 1
- 漏警概率 PM（H1 为真判 H0）+ 检测概率 PD = 1
- 4 类中只有 2 类独立，影响性能的主要因素是信噪比

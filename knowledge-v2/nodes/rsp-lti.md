## 一句话本质

随机过程过 LTI 系统，输出功率谱 S_YY(f) = |H(f)|² · S_XX(f)——系统不改变谱的形状类别，只按 |H(f)|² 加权缩放。

## 为什么需要它

随机信号在通信/滤波里都要经过系统，要知道输出的统计特性（均值/自相关/功率谱）怎么变，才能分析噪声抑制、信噪比优化。

## 核心机制（一条链）

输入 X（宽平稳）→ LTI 系统 h(t) → 输出 Y = X*h → 均值 μ_Y=μ_X*h → 自相关 R_YY=R_XX*h(τ)*h(-τ) → 功率谱 S_YY=|H(f)|²·S_XX

## 关键结论（面试必答）

- 输出均值：μ_Y = μ_X * h（卷积）
- 输出自相关：R_YY = R_XX * h(τ) * h(-τ)
- 输出功率谱：**S_YY(f) = |H(f)|² · S_XX(f)**（关键公式）
- 白噪声经低通 → 带限噪声（谱形状按 |H|² 加权缩放）
- 离散域：S_yy(z) = H(z)H(z⁻¹)S_xx(z)，引出 AR/MA/ARMA 模型

## 随机信号中的滤波器计算

IIR/FIR 滤波器的随机信号计算，本质就是：白噪声激励下，用 S_YY = |H(f)|²·S_XX 求输出功率谱，或用差分方程（H(z) 表示）求输出的自相关函数和功率谱。

## 一句话本质

计算机网络 = 分层体系结构（OSI 七层 / TCP/IP 四层），核心是分层——每层只做一件事，封装/解封装贯穿始终。

## 为什么需要分层

网络功能太复杂（多主机、多协议、多应用），无法整体设计。分层让每层专注一件事，向上提供服务、向下调用服务，实现解耦和独立演进。

## 核心机制（封装/解封装）

发送端：应用数据 → 传输层加 TCP 头 → 网络层加 IP 头 → 链路层加帧头 → 物理层比特流
接收端：逐层剥头还原

## 分层结构

| 层 | 功能 |
|----|------|
| 物理层 | 比特传输 |
| 数据链路层 | 帧、差错控制、MAC 寻址 |
| 网络层 | 路由、IP 寻址、拥塞控制 |
| 传输层 | 端到端、TCP/UDP |
| 会话/表示/应用层 | 会话管理、格式转换、网络服务 |

## 关键结论（面试必答）

- OSI 七层 vs TCP/IP 四层：TCP/IP 把会话/表示层并入应用层，把物理/链路层合并为网络接口层
- 网络协议三要素：语法、语义、语序
- 数据报（无连接，独立路由）vs 虚电路（面向连接，顺序交付）

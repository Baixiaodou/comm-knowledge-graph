## 一句话本质

S 参数（散射参数）= 射频网络的**黑盒语言**：把器件看成端口网络，用「入射波 a / 反射波 b」的比值描述它，**测量不需要端口开路或短路**——这是它与低频 Z/Y 参数的本质区别，也是射频器件指标（回波损耗、插入损耗、隔离度）的标准表述。

## 为什么需要它

低频测量网络用 Z/Y/H 参数，需要端口**开路/短路**。但射频下开路会辐射、短路有寄生电感，无法精确实现。S 参数改测**行波**（入射波/反射波），用定向耦合器就能分离，矢量网络分析仪（VNA）直接测的就是 S 参数。所以**射频工程师的"语言"是 S 参数**：datasheet 上的 S11、S21 就是它。

## 核心机制（一条链）

器件看作 N 端口网络 → 每个端口定义归一化入射波 aᵢ 与反射波 bᵢ → **b = S·a**（S 为散射矩阵）→ 各元素含义：**S11=端口1反射系数（1口入射、1口出，其余口接匹配）**，S21=1→2 传输系数（增益/插损），S12=反向隔离，S22=端口2反射 → 全部在**参考阻抗 Z0（通常 50Ω）**下定义。

## 关键结论（面试必答）

### S11 ↔ 回波损耗 ↔ VSWR 三换算（背熟）

| 量 | 关系式 |
|----|--------|
| 反射系数 | Γ = S11（在 50Ω 参考系下） |
| 回波损耗 | RL(dB) = −20·lg|S11| |
| 驻波比 | VSWR = (1+|S11|)/(1−|S11|) |

**数值速记**：S11=−10 dB → |Γ|=0.316 → VSWR≈1.92 → 反射功率 |Γ|²≈10%、传输 90%。**工程判据：S11<−10dB 通常视为匹配合格。**

### 双端口 S 参数语义

| 参数 | 含义 | 工程口语 |
|------|------|---------|
| S11 | 输入回波损耗 | 「匹配好不好」（天线/BJT 输入） |
| S21 | 正向传输系数 | 无源=插入损耗(负)，有源=增益(正) |
| S12 | 反向传输/隔离 | 「反向隔离够不够」（混频器/放大器） |
| S22 | 输出回波损耗 | 输出匹配 |

### 两条性质

- **互易网络**：S12=S21（无源无源器件成立）
- 无源网络 |S11|²+|S21|²≤1（能量守恒，多余部分是损耗）

### 项目语境（巴伦/天线）

- 巴伦平衡端的不平衡 → 共模辐射/损耗，常用 S 参数差（S21 幅度/相位不平衡度）量化 → 决定共模抑制比/镜像抑制
- 天线：S11 是**天线设计第一指标**——馈线 Z0(50Ω) 与天线输入阻抗失配多大，S11 直接给出

## 代价与权衡

- S 参数是**线性小信号**描述：大信号（功放压缩）、非线性（谐波/交调）需额外测功率参数，S 参数不够
- 数值依赖**参考阻抗**：同一器件在 50Ω 与 75Ω 下 S11 不同，必须标明
- 只能描述端口行为，**不直接给内部电路信息**——设计仍需回到 Z/Y 参数或电路级仿真

## 一句话本质

冲激响应不变法（保时域混叠）vs 双线性变换法（保频域需预畸变），继承模拟滤波器


## 核心理解

IIR 的设计理念：**通过优秀的模拟滤波器**（S 域设计已经很成熟），用 s→z 映射转到数字域。两条思路：

## 冲激响应不变法：保时域，牺牲频域

- 思想：h(n) = h_a(nT)（对模拟冲激响应采样）
- 频域后果：时域采样 ⇔ 频域周期延拓 → **频域混叠**
- 致命缺陷：模拟滤波器阻带在高频不为零，延拓后折回通带
- **只能用于低通/带通（严格带限），不能用于高通/带阻**

## 双线性变换法：保频域，牺牲线性

- 思想：非线性映射 s = (2/T)(1-z^-1)/(1+z^-1)，把 s 平面整个虚轴压缩到单位圆
- 关键性质：左半平面↔单位圆内（稳定保持）、虚轴↔单位圆（一一对应**无混叠**）
- 频率非线性压缩：Ω = (2/T)tan(ω/2)，模拟无限频率范围「折叠」进数字有限范围
- **代价：频率轴非线性畸变 → 需要预畸变**：设计前先按 Ω_c = (2/T)tan(ω_c/2) 反算截止频率

## 对比总结

| | 冲激响应不变法 | 双线性变换法 |
|---|--------------|-------------|
| 保持量 | 时域冲激响应 | 频域幅度形状 |
| 混叠 | 有（频域混叠） | 无 |
| 频率线性 | 线性 | 非线性（需预畸变） |
| 适用范围 | 低通/带通 | 全部类型 |

**统一视角**：冲激响应不变法的混叠 = 采样定理的混叠（同一回事）；双线性变换用非线性频率压缩巧妙绕开。

## 模拟原型滤波器

巴特沃斯（最平坦）、切比雪夫 I/II（等纹波）、椭圆（最陡）。IIR 阶数低、实现简单，语音里用得多。

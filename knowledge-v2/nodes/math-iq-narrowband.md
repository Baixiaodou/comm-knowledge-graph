## 一句话本质

从实信号（窄带过程）出发，用 sin/cos 正交分解 + 欧拉公式收拢出复包络，再采样成星座点、按 log₂M 分组映射——这就是欧拉公式通向数字调制器每一级开关的完整链。

## 完整链路（四步推演）

### ① 窄带过程 → sin/cos

任何窄带实信号（带宽 B << 载频 f₀）都可写成：
s(t) = a(t)·cos(ω₀t + φ(t)) —— 幅度和相位都慢变（因为窄带）

### ② 三角展开 → 正交分量

用两角和的余弦展开，得到**两路正交分量**：

```
s(t) = a(t)cosφ(t)·cosω₀t − a(t)sinφ(t)·sinω₀t
     =   I(t)·cosω₀t      −   Q(t)·sinω₀t
```

- **I(t) = a(t)cosφ(t)**：同相分量（in-phase），乘 cosω₀t 那一路
- **Q(t) = a(t)sinφ(t)**：正交分量（quadrature），乘 sinω₀t 那一路
- cosω₀t 与 sinω₀t 正交（一个周期内积为 0）→ 两路可独立承载信息、互不干扰

### ③ 欧拉公式 → 复包络

用欧拉公式把两路收拢成一个复函数：

```
s(t) = Re{ [I(t) + jQ(t)] · e^{jω₀t} }
```

- 复包络 g(t) = I(t) + jQ(t)：窄带过程的**全部信息**（幅度 a、相位 φ 两个自由度）
- 通带分析 → 基带分析：甩掉高频振荡 e^{jω₀t}，只看低频复包络（等效基带）
- 这一步就是"为什么数字收发机全是 I/Q 两路"的数学根源

### ④ 采样 → 星座图 → 多进制

- 符号时刻对 I(t)、Q(t) 采样 → 复平面上的一个点 (I, Q)
- **M-ary 调制** = 预选 M 个合法点，每符号携带 log₂M bit：BPSK 2 点 / QPSK 4 点 / 8PSK 8 点 / 16QAM 16 点
- 星座点间距 d 决定抗噪能力（点越密 → 每符号 bit 越多 → 越省带宽但越怕噪声）

## 串并变换（调制解调前后的关键操作）

```
发射：串行比特流 ──按 log₂M 分组── 串/并 ──每组映射一个星座点(I,Q)── I/Q 两路并行 ── 正交载波调制
接收：解调出(I,Q) ── 判决到最近星座点 ── 并/串 ── 还原串行比特流
```

- 为什么需要：M-ary 每个符号对应 log₂M 个 bit，串行比特流必须**按符号粒度分组**后才能映射星座点
- 串/并：把 1 路高速比特流变成 log₂M 路并行（符号映射器的输入）
- 并/串：接收端判决出符号后，把并行 bit 还原成串行流
- 注意：串并变换 ≠ 串/并转换器（多路传输用），这里是"比特→符号"的粒度重组

## 关键结论（面试必答）

- 窄带信号 I/Q 分解**唯一**（cos/sin 正交），是模拟/数字调制共用的底层
- 复包络表示 = 从通带"搬家"到基带，一切分析（滤波/估计/检测）在基带做
- M-ary 的权衡：每符号 bit 越多 → 速率越高但星座越密 → 抗噪越差（用功率换速率）
- 串并变换是调制器**最前端**、解调器**最后端**的操作，本质是"比特流↔符号流"的粒度转换

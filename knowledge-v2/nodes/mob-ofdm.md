## 一句话本质

OFDM 把一路高速数据拆成 N 路低速正交子载波，用 CP 把线性卷积变循环卷积，从而把频率选择性信道分解成若干平坦子信道。

## 为什么需要它

多径导致频率选择性衰落 → 码间串扰 ISI。宽带信号符号周期短、时延扩展明显，被 ISI 严重破坏。核心思路：串/并转换让符号周期变长 N 倍，从容对抗时延扩展。

## 核心机制（一条链）

高速流 → 串/并转换 N 路低速子载波 → 子载波正交（Δf 精确）→ IFFT/FFT 调制解调 → 加 CP（长度 > 最大时延扩展）→ 线性卷积变循环卷积 → FFT 后信道对角化 → 各子载波独立（无 ICI）

## 关键结论（面试必答）

- 子载波正交 → 频谱重叠但互不干扰 → 比 FDM 省一半频谱，接近奈奎斯特极限
- CP > 最大时延扩展（> 卷积尾巴长度）→ 消除 ISI
- CP 用循环卷积不用补零 → 既消 ISI 又保子载波正交（ICI）；补零只能消 ISI、不能保正交
- IFFT/FFT 实现 → O(N·logN)，是"思路变现实"的工程关键
- FFT 后信道成对角矩阵 → 频率选择性信道被分解成若干平坦子信道，只需单抽头均衡

## 代价与权衡

- PAPR 高：子载波多、相位叠加峰值高 → 放大器线性区受限 → 用限幅/编码/预留子载波处理
- 对频偏敏感：Δf 精确、多普勒破坏正交性 → 加导频 + 频偏估计补偿
- 权衡：用 CP 开销 + PAPR 代价，换抗多径 ISI 的能力（呼应全库"资源换性能"的权衡）

## 三个视角（跨树收敛）

| 视角 | 树 | 侧重点 |
|------|-----|--------|
| 复用多载波 | 通信原理 | OFDM 是频域复用的极致 |
| IFFT/FFT + 循环卷积 | DSP | OFDM 是 DFT 最成功的工程应用 |
| 抗频率选择性衰落 | 移动通信 | OFDM 是对抗多径 ISI 的最佳手段 |

## 核心理解

以**通信工程**为领域的个人知识体系。三层统一于节点（节点即一切）：

- 树结构表达「是什么」：概念的层级归属（parent/children）
- Wiki 连接表达「和什么相关」：跨学科、跨模块的语义关联（links）
- 思维链表达「为什么这样想」：核心概念的推理路径（cot）

## 四层架构（借鉴知识图谱「领域-主题-概念-实例」组织法）

| 层 | 本库中的位置 | 实例 |
|----|------------|------|
| **领域层** | root | 通信工程（未来可扩展：计算机、数学基础…） |
| **主题层** | 一级节点（课程） | 通信数学、通信原理、信号与系统与DSP、移动通信、随机信号处理、电磁场、计算机网络 |
| **概念层** | 二级分支（模块） | 数字调制、信道、变换域、采样与重建… |
| **细节层** | 叶子节点的 `## 小节` | 采样/量化/蝶形运算/预加重… |

层级规则：树管「在哪」（分类归属），Wiki 管「和谁相关」（语义关联），cot 管「怎么想」（推理路径）。

## 七棵主题树的关系

- **通信数学（math-principles）**：数学地基，问「用什么数学语言」——微积分（分解）、线代（线性变换）、概统（噪声与估计），只保留与通信紧密相关的核心工具
- **通信原理（comm-principles）**：绝对核心，问「系统怎么搭、资源怎么权衡」——理论极限与工程实现的权衡
- **信号与系统与DSP（dsp-principles）**：工具课，问「确定信号怎么算、怎么处理」——微积分基础，提供时频数学工具
- **随机信号处理（rsp-principles）**：工具课，问「随机信号怎么分析」——概率统计基础，提供功率谱/噪声工具
- **移动通信（mob-principles）**：应用外延，问「工程怎么落地、怎么服务多用户」——特定场景（移动信道）的延伸
- **电磁场（emf-principles）**：物理基础，问「电磁波怎么来」——麦克斯韦→电磁波→天线，信号载体的来源
- **计算机网络（net-principles）**：应用延伸，问「多主机怎么组网」——分层（封装/解封装），更宏观的通信组织
- 关系一句话：**数学地基 → 工具课（DSP+随机信号）→ 通信原理（绝对核心）→ 应用（移动通信/高频电路/计网/电磁场）**，硬件整体偏外
- 七树间现有 70+ 条跨学科连接（OFDM↔FFT、扩频↔香农、CSMA/CD↔多址、差错控制↔信道编码、匹配滤波↔信号检测、电磁波↔路径损耗、泰勒↔功放非线性、CLT↔AWGN…），检索时按问题自动跨树取节点，这是「树+Wiki 跨学科融合」的核心价值

## 组织原则（知识图谱三要素：节点 / 关系 / 组织原则）

1. **先框架后内容**：每层先有框架节点（root、课程根、内容多的模块），links 写部分间关系，子节点写具体内容
2. **核心枢纽**：每门课一个贯穿性枢纽（通信原理=权衡；DSP=对偶对称；移动通信=三大根本矛盾；随机信号处理=维纳-辛钦），写成 core 节点的 cot
3. **关系类型约定**：links 的 relation 建议语义化，常用类型：对偶 / 镜像 / 支撑 / 应用 / 同源 / 区分 / 对抗 / 对应
4. **渐进扩展**：新课程按「口述 → 讨论结构 → 建节点 → lint 校验 → benchmark」流程接入主题层
5. **结论式写法**：节点 content 用「一句话本质 → 为什么 → 核心机制（→链）→ 关键结论 → 权衡」模板，结论前置方便 AI 提取

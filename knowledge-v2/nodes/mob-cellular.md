## 一句话本质

蜂窝组网 = 空间维度的频率复用，用距离隔离换频谱复用，是宏观层面的分集。

## 为什么需要它

频谱有限但用户众多 → 空间分割：把大区域划成小区，不同小区复用同一段频率。

## 核心机制（一条链）

划小区（小区制）→ N 小区组区群 → 区内频率不同、区群间频率复用 → 用距离隔离同频干扰

## 关键结论（面试必答）

- 区群大小 N = a² + ab + b²（a、b 自然数不同时为 0），同频间距 d = √(i²+ij+j²)·R
- 核心权衡：区群 N 越大 → 同频距离越远 → 干扰越小，但复用效率越低
- 小区分层：宏小区/微小区/微微小区/毫微微小区（femto）

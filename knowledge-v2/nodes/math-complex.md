## 一句话本质

复变函数是微积分在复数域的推广，欧拉公式 e^{jθ}=cosθ+jsinθ 是通信的数学母语：**复指数 = 旋转**。

## 为什么需要它

- 复指数同时携带幅度+相位，且乘法 = 旋转 + 伸缩——恰好匹配调制/混频的"频率搬移"本质
- 用复数运算替代三角运算，傅里叶变换、调制解调、滤波的全部推导都大幅简化
- 频谱天然是复的（幅度谱+相位谱），不用复数根本没法完整描述信号

## 核心机制（欧拉公式 = 泰勒展开的赠品）

1. 泰勒展开：e^x = 1+x+x²/2!+…，cosx = 1−x²/2!+x⁴/4!−…，sinx = x−x³/3!+…
2. 令 x = jθ 代入 e^x，按实部/虚部分组
3. 实部恰是 cosθ 的级数、虚部恰是 j·sinθ 的级数 → e^{jθ} = cosθ + jsinθ
4. 逆用：cosθ = (e^{jθ}+e^{-jθ})/2，sinθ = (e^{jθ}−e^{-jθ})/2j —— 这解释了"实信号频谱正负对称"

## 关键结论（面试必答）

- **复数乘法 = 模相乘、辐角相加**：乘 e^{jθ} 就是旋转 θ 角（载波就是匀速旋转的指针）
- **欧拉公式推导**：泰勒展开 e^{jθ} 按实虚部分组（背下这条因果链，面试加分）
- **解析信号**：xₐ = x + j·Hilbert(x)，频谱只剩正频 → SSB 单边带、包络提取的数学
- **IQ 调制**：s(t) = Re{(I+jQ)·e^{jωt}}，信息全在复包络，星座图 = 复平面上复包络的取值集合
- **极点零点**：分母=0→极点（生峰）、分子=0→零点（生谷），极点位置定稳定性——细节见 dsp-laplace-z
- 了解级（会一句话）：解析函数/C-R 条件、留数定理（围道积分 = 2πj×留数和）
